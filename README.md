# House Price Prediction Model

## 📌 Description
This project predicts house prices based on various features such as area, amenities, and furnishing status using machine learning.

## 🚀 Features
- Data preprocessing and encoding
- Feature scaling
- Linear Regression model training
- Model evaluation using MAE and R² score
- Data visualization using heatmaps

## 🛠 Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## ▶️ How to Run
1. Clone the repo
2. Install dependencies:
   pip install -r requirements.txt
3. Run:
   python src/main.py

## 📊 Output
- Displays model performance metrics
- Shows correlation heatmap
